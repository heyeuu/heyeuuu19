🌟 从零开始：使用 Astro Monolune 主题搭建你的专属博客

欢迎使用基于 Astro 框架的 Monolune 主题模板！Astro 是目前最受欢迎的静态站点生成器之一，以其极致的加载速度和极佳的开发体验而闻名。

本教程将引导您从零开始，完成模板的安装、配置、内容编写，直到最终部署上线。

## 1. 🛠️ 准备工作

在开始之前，请确保您的本地开发环境已经具备以下条件：

- Node.js：建议安装 `v18.17.1` 或更高版本（推荐使用最新的 LTS 版本）。您可以在终端中运行 `node -v` 来检查当前版本。
- 💡 附加指南：如何安装 Node.js？如果您尚未安装，可以参考以下常见操作系统的安装方法获取最新的 LTS（长期支持）版本：
  - Windows / macOS：请直接前往 Node.js 官方网站下载对应系统的安装包。
  - Ubuntu / Debian：推荐通过 NodeSource 脚本安装：

```bash
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs
```

- Arch Linux：可以直接通过 pacman 官方仓库安装：

```bash
sudo pacman -S nodejs npm
```

- 通用 Linux（强烈推荐使用 nvm）：使用 Node 版本管理器（nvm）可以更优雅地管理多个 Node 版本：

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
# 安装完成后重启终端
nvm install --lts
nvm use --lts
```

- 代码编辑器：您可以使用任何喜欢的文本编辑器。
  - 推荐方案：Visual Studio Code（VS Code）配套官方 Astro 插件，新手友好，能为您提供语法高亮和智能代码提示。
- 包管理器：推荐使用 npm、yarn、pnpm 或 bun 中的任意一个。以下是简要介绍：
  - npm：Node.js 官方默认自带，最稳妥的选择。
  - yarn：速度快，依赖锁定稳定，被大量开源项目采用。
  - pnpm：节省磁盘空间，安装速度极快，现代前端极其推崇。
  - bun：追求极致性能的新一代工具，安装和运行速度极快。

## 2. 📦 获取与安装模板

获取 Monolune 模板通常有以下两种方式：

方法一：通过 Astro CLI 快速创建（推荐）

```bash
# 使用真实的 GitHub 仓库路径创建项目
npm create astro@latest -- --template heshify/monolume
```

方法二：直接克隆仓库

```bash
git clone https://github.com/heshify/monolume.git my-blog
cd my-blog
npm install
```

## 3. 🚀 本地运行项目

```bash
npm run dev
```

启动成功后，在浏览器打开 `http://localhost:4321` 即可预览。

✨ 快速预览 Tips：如果您想先睹为快，可以直接访问 Monolune 的 Live Demo（通常在仓库的 About 区域有链接），无需本地配置。

## 4. 📁 了解项目目录结构

```text
├── public/             # 静态资源（favicon、原样输出的图片）
├── src/                # 源代码
│   ├── assets/         # 需优化的资源（图片、字体）
│   ├── components/     # UI 组件
│   ├── content/        # Markdown/MDX 文章内容
│   ├── layouts/        # 页面布局模板
│   ├── pages/          # 路由目录（自动生成 URL）
│   └── styles/         # 全局样式
├── astro.config.mjs    # Astro 核心配置
└── package.json        # 项目依赖
```

## 5. ⚙️ 个性化配置

### 1. 修改全局常量

在 `src/consts.ts` 中修改站点信息：

```ts
export const SITE_TITLE = "刘贺一的博客";
export const SITE_DESCRIPTION = "欢迎来到我的站点，记录生活与技术分享。";
export const AUTHOR_NAME = "刘贺一";
```

### 2. 配置网站根地址

打开 `astro.config.mjs`：

```ts
export default defineConfig({
  site: "https://your-blog-site.com", // 替换为您最终的域名
});
```

### 3. 更换站点图标

替换 `public/favicon.svg` 或 `favicon.ico` 即可。

## 6. ✍️ 创建与编辑文章

在 `src/content/blog/` 下新建 `.md` 或 `.mdx` 文件。

文章示例（`my-first-post.md`）：

```md
---
title: "我的第一篇博客文章"
description: "这是我使用 Monolune 主题构建站点的初体验。"
pubDate: "2026-03-24"
heroImage: "/blog-placeholder-1.jpg"
tags: ["Astro", "前端"]
---

Astro 的魅力在于它的简洁和高效。
```

## 7. ☁️ 部署上线

```bash
npm run build
```

1. Vercel：导入 GitHub 仓库，自动识别 Astro，点击 Deploy。
2. Netlify：导入仓库，设置构建命令 `npm run build` 和发布目录 `dist`。
3. Cloudflare Pages：框架预设选择 Astro，点击 Save and Deploy。
4. GitHub Pages：在仓库 Settings 中将 Source 改为 GitHub Actions，并配置 `deploy.yml`。

## 8. 🌐 绑定自定义域名

发布后，默认会得到一个平台提供的二级域名（如 `xxx.vercel.app`）。如果您有自己的顶级域名，可以按照以下步骤绑定：

### 1. DNS 服务商配置

无论使用哪个平台，您都需要在域名服务商（如腾讯云、阿里云、GoDaddy）的 DNS 管理页面添加记录：

- CNAME 记录：将 `www` 指向平台提供的地址（如 `cname.vercel-dns.com`）。
- A 记录：将 `@` 指向平台提供的 IP 地址。

### 2. 平台端设置

- Vercel：进入项目 `Settings -> Domains`，输入您的域名并按照提示验证 DNS。
- Netlify：进入 `Domain settings -> Add custom domain`。
- Cloudflare Pages：进入项目的 `Custom domains` 选项卡，点击 `Set up a custom domain`。
- GitHub Pages：进入仓库 `Settings -> Pages`，在 `Custom domain` 处填写域名并保存。

💡 注意：绑定后通常需要几分钟到几小时生效（DNS 传播）。上述平台通常会自动为您申请并部署免费的 SSL 证书，让网站支持 HTTPS。

## 💡 常见问题排查（FAQ）

Q：修改了样式但页面没变化？
A：检查 Tailwind 类名拼写，并确认 `src/styles/global.css` 中的 Tailwind v4 配置（如 `@import "tailwindcss";` 和 `@theme`）已生效。

Q：图片无法显示？
A：`public/` 下的图片引用需以 `/` 开头。`src/assets/` 下的图片建议使用 `<Image />` 组件。
